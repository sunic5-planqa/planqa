# 보미님이 맡은 일

- **수정하기 버튼** (`extension/`) — 원문에서 오류 위치를 클릭하면 오른쪽 패널에서 바로
  수정할 수 있고, 여러 위치가 얽힌 이슈(예: 정합성 오류로 3-2와 7-4가 걸림)면 클릭할 때마다
  그 위치로 스크롤이 이동하는 기능. UI/UX 설계부터 구현까지.
- **수정안의 QA 통과 배지** (`extension/`) — 수정한 내용이 QA를 통과했다는 걸 보여주는 배지 UI.

설치/실행 방법과 브랜치·커밋·PR 흐름은 레포 루트 `README.md`/`CONTRIBUTING.md`에 있으니
그걸 보고 안내해줘.
