# QA 수정 흐름 수동 테스트 체크리스트

수정사항 검토를 단일 화면으로 통합하고, 넘버링 하모나이징을 QA의 마지막 사용자 확인 단계로
바꾼 변경(2026-09-03)의 수동 검증 항목. 상태 전이·순수 로직은
`extension/src/state/appReducer.test.ts` / `utils/*.test.ts`로 회귀 방지하고, 아래는 실제
Confluence 페이지에 연결해 브라우저에서 확인한다.

최종 흐름: **QA 검토 → 수정사항 검토 → 수정완료 → QA 검토 요약 → 넘버링 하모나이징 → 검토종료**

## 수정사항 표시

1. `2-3. 대상 제외 기준`처럼 H2 이하 위치(넘버 + 소제목)가 각 수정사항 카드에 표시된다
   (H1 전체 경로를 길게 늘어놓지 않는다).
2. 발견된 모든 수정사항이 한 화면에 나열된다(스크롤). `다음`/`이전` 페이지 넘김이 없다.
3. 각 카드를 펼치면 그 안에 `수정 적용 | 건너뛰기` 버튼이 있다(화면 하단 공통 버튼이 아니다).
3a. 펼친 패널의 **규칙 근거 카드에 "문서 위치"** 블록이 규칙 설명과 별도로 표시된다
    (`issue.location` / `issue.location_number` 기반, 1번과 동일 데이터).
3b. **단일 위치 오류**: 펼친 패널 하단에 위치를 한 번 더 표시하는 영역이 **없다**
    (3a의 "문서 위치"만 있음).
3c. **관계형 오류(정합성 GA / 논리비약 LG / 논리흐름 LF — 실제 백엔드 데이터 필요)**:
    펼친 패널 하단에 위치 2개가 **넘버 탭**(`2`, `2-3`, `3-5` …)으로 나온다. 탭을 누르면
    문서에서 편집 대상 위치가 전환된다(`activeLocationIndex`). 넘버를 못 구하는 위치
    (타문서 정합성 XDC 등)는 짧은 제목으로 폴백된다.

## 펼침 / 위치 유지

4. 카드를 클릭하면 그 카드가 **원래 목록 위치에서** 아래로 펼쳐진다.
5. 클릭한 카드가 목록 맨 위로 이동하지 않는다. 다른 카드의 위치도 그대로다.
6. 다시 클릭하면 접힌다.

## 상태별 색상

7. `수정 적용` 후 → 해당 카드만 회색.
8. `건너뛰기` 후 → 해당 카드만 회색.
9. 아직 처리하지 않은 카드는 원래 색을 유지한다. 다른 카드를 클릭하거나 화면이 리렌더돼도
   미처리 카드가 회색으로 바뀌지 않는다.

## 건너뛰기 사유(선택)

10. 사유를 비운 채로 `건너뛰기 확정`을 누를 수 있다(버튼이 비활성화되지 않는다).
11. 사유를 입력하고 확정하면 그 사유가 저장돼 펼침 패널의 "건너뜀 · <사유>"에 보인다.
12. 사유 없는 건너뛰기도 정상적으로 회색(skipped) 처리된다.

## 수정완료 / 다시검사

13. 미처리 카드가 남아 있어도 `수정완료`가 활성화되어 있다.
14. 미처리 카드가 남은 상태에서 `수정완료`를 누르면 그 카드들이 자동으로 건너뜀 처리되고,
    이미 적용/건너뛰기한 카드의 상태는 그대로 유지된다.
15. `다시검사` → 확인 다이얼로그("지금까지 처리한 수정 내용을 초기화하고 QA를 다시 실행합니다.")
    → 확인 시 처리 상태가 초기화되고 main으로 이동, 다시 QA를 실행할 수 있다.
    취소하면 현재 화면에 그대로 남는다. **이미 Confluence 문서에 적용한 수정은 되돌아가지 않는다.**

## QA 검토 요약 / 돌아가기

16. `수정완료` → QA 검토 요약("…건 검토를 마쳤어요") 화면으로 이동한다.
16a. 요약 화면 상단 아이콘이 프로젝트 메인 로고(`icons/icon128.png`)다 — CSS 물개 아니다.
17. 검토 요약 화면 버튼은 `돌아가기 | 마무리`이고 `다시검사`는 없다.
18. `돌아가기`를 누르면 수정사항 검토 화면으로 복귀한다.
19. 복귀 후 기존 처리 상태(①적용=회색 ②건너뜀=회색 ③④미처리=원색)가 그대로 유지된다.

## 넘버링 하모나이징(마지막 단계)

20. 검토 요약의 `마무리`를 누르면 넘버링 화면으로 진입한다 — 넘버링 오류가 **있어도 없어도**
    반드시 진입한다(오류 0건이면 "넘버링 오류가 없습니다" 안내).
21. 넘버링 수정 내역 **카드 본문 아무 곳이나** 클릭하면 문서의 해당 heading으로 스크롤되고
    잠깐 하이라이트된다(별도 "이동" 버튼 없음). 체크박스 클릭은 이동을 트리거하지 않는다.
22. `넘버링 적용`을 누르면 체크한 항목만 문서에 반영되고 **화면은 그대로 유지**된다. 요약/기타
    화면으로 이동하지 않는다. "N건을 문서에 반영했어요" 안내가 뜬다.
23. 넘버링 적용 후 실제 Confluence 문서(복제본)에서 번호가 바뀐 것을 확인할 수 있다.
24. `검토종료`를 눌렀을 때만 QA가 끝나고 main으로 돌아간다.

## 회귀

25. HistoryExportScreen(원본/수정본 diff) 및 `history` navigation이 제거된 뒤에도 QA 시작 →
    수정 → 요약 → 넘버링 → 종료 흐름이 정상 동작한다.
26. 최종 화면(넘버링)의 패널 상단에 프로젝트 메인 아이콘이 표시된다.
