# 승현님이 맡은 일

- **타문서 검토 대상 적용** (`backend/`) — 지금은 기획서 한 종류만 검토하는데, 다른 문서
  종류도 검토 에이전트로 넘길 수 있게 백엔드 라우팅을 손보는 작업.
- **'오류 원문' 넘버링 오류 진단** — 검토 결과에 찍히는 위치(넘버링)가 실제로 잘못 잡힌 건지,
  아니면 LLM이 순서를 헷갈린(hallucination) 건지 원인 확인. 코드 변경 전에 `planqa-agent`
  레포의 검토 결과(`review.json`의 `location` 필드)부터 들여다봐야 할 수도 있음 — 재현 사례를
  찾아서 이슈로 남기는 정도로 충분.

설치/실행 방법과 브랜치·커밋·PR 흐름은 레포 루트 `README.md`/`CONTRIBUTING.md`에 있으니
그걸 보고 안내해줘.
