# 온보딩 문서 (처음 기여하는 사람용)

이 폴더는 사람 이름별로 "지금 뭘 해야 하는지"를 정리한 문서입니다. Claude Code든 다른 AI
도구든, 심지어 사람이 직접 읽어도 되도록 평문으로 씁니다.

이 폴더 파일에는 **"누가 뭘 맡았는지"만** 있다. 설치/실행 방법과 브랜치·커밋·PR 흐름은
레포 루트 `README.md`/`CONTRIBUTING.md`가 원본이므로 여기 베끼지 않는다 — AI 도구가 그때
그때 그 문서를 읽어서 안내한다.

## 사용법

- **Claude Code 쓰는 사람**: 세션 시작할 때 "나는 보미야" 처럼 이름만 말하면 됩니다.
  `CLAUDE.md`에 이 폴더를 자동으로 찾아 안내하라는 지침이 있어요.
- **다른 AI 도구(GPT 등) 쓰는 사람**: `docs/onboarding/<이름>.md` 파일을 직접 열어서
  내용을 그대로 그 도구에 붙여넣고 시작하면 됩니다 — 이 폴더는 특정 도구 전용 기능에
  기대지 않습니다.
- **AI 없이 직접 하는 사람**: 그냥 읽고 그대로 따라 하면 됩니다.

공통 배경(브랜치 전략, 커밋 형식, `.env` 관련 주의사항 등)은 [`CONTRIBUTING.md`](../../CONTRIBUTING.md)에
있고, 여기 개인별 문서는 "나는 뭘 맡았고 어디서 작업하는지"만 추가로 다룹니다.
