# 은성님이 맡은 일

- **팀룰 추가 기능** (`extension/`) — 팀마다 자기 도메인 룰을 추가할 수 있게 하는 기능.
  와이어프레임부터(어떤 내용을 입력받을지, 화면 흐름) 승인받은 뒤 실제 구현까지.
  - 참고: 이 기능의 백엔드/데이터 설계는 `planqa-agent` 레포의
    `services/review-agent/docs/adr/0001-team-rule-authoring.md`에 이미 있음. "사람이
    자연어로 룰 입력 → 시스템이 초안(카테고리/티어/예시) 생성 → 사람이 확인 후 확정" 흐름.
- **넘버링 하모나이징** (`extension/`) — 문서 안 넘버링 체계 통일. 정확한 범위는 혜서/가영과
  먼저 확인 필요.

설치/실행 방법과 브랜치·커밋·PR 흐름은 레포 루트 `README.md`/`CONTRIBUTING.md`에 있으니
그걸 보고 안내해줘.
